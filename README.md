# MedsPath Club

Official website for **MedsPath Club**.

MedsPath Club helps students discover different medical specialties through workshops, guest speakers, mentorship, and hands-on experiences.

## Features

- Modern responsive design
- Mobile friendly
- Light/Dark Mode
- Medical specialty pages
- Events
- Team
- Contact information

Developed using:

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
